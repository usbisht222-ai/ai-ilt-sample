# Prompting for Better Work Outputs

**Format:** Live session (in-person or virtual) · **Duration:** 60 minutes · **Audience:** Non-technical professionals new to generative AI · **Group size:** 12–20

## Learning Objectives

By the end of this session, learners will be able to:

1. Identify why a vague prompt produces a weak AI output.
2. Write a structured prompt using **Role, Context, Task, Format, Constraints**.
3. Improve a weak AI output through at least two follow-up prompts.
4. Name two types of information they should never enter into a public AI tool.

## Prerequisites

- Learners have access to one AI chat tool (ChatGPT, Claude, Gemini or Copilot).
- Learners bring one real work task they would like help with (an email, summary or report).

### 0:00–0:05 · Opening hook

Show two AI outputs side by side for the same request: one from a one-line prompt, one from a structured prompt.

**Ask:** "Same tool, same request. Why is the second one so much better?"

> **Facilitator note:** Take 2–3 answers. Don't explain yet. The goal is curiosity, not the answer.

### 0:05–0:15 · The five-part prompt (I Do)

Introduce the structure on one slide:

- **Role:** Who should the AI act as?
- **Context:** What background does it need?
- **Task:** What exactly should it do?
- **Format:** What should the output look like?
- **Constraints:** Length, tone, what to avoid.

Live demo: build a prompt for "Write an email to a client about a delayed delivery" one part at a time. Run it after each addition so learners see the output improve.

> **Facilitator note:** Narrate your thinking out loud ("I'm adding tone here because this client is already upset"). This is the most important part of the demo.

### 0:15–0:25 · Fix a weak prompt (We Do)

Put a weak prompt on screen from the weak prompt bank, for example: *"Summarise this report."*

As a group, rebuild it using the five parts. Learners call out each part; you type.

> **Facilitator note:** If the group goes quiet, prompt them: "Who is reading this summary? What will they do with it?"

### 0:25–0:45 · Prompt lab (You Do)

In pairs (breakout rooms if virtual):

1. Each learner writes a prompt for their own work task using the worksheet.
2. They run it and rate the output from 1 to 5.
3. Their partner suggests one improvement.
4. They write **two follow-up prompts** to improve the output and rate it again.

> **Facilitator note:** Visit each pair or room. Common mistakes to watch for:
> - Leaving out context ("the AI can't read your mind")
> - Accepting the first output without refining it
> - Pasting confidential client details into the tool

### 0:45–0:52 · Responsible use

**Ask:** "What should never go into a public AI tool?"

Expected answers: client personal data, confidential financials, passwords, unreleased company information. Add the habit: **always check facts before sharing AI output.**

### 0:52–1:00 · Debrief and exit ticket

**Debrief questions:**
- What changed most between your first and last output?
- Which of the five parts made the biggest difference?
- Where will you use this tomorrow?

**Exit ticket (in chat or on paper):** Write one five-part prompt you will reuse at work.

## Assessment

| Objective | How it is checked |
|---|---|
| 1 | Hook discussion and We Do responses |
| 2 | Prompt written on the worksheet during the lab |
| 3 | Before and after ratings, with two follow-up prompts |
| 4 | Responsible use discussion and exit ticket |

## Adapting this lesson

- **For technical teams:** swap the email task for code review or documentation tasks.
- **For a longer session:** add a round where pairs compare outputs from two different AI tools.
- **For virtual delivery:** use polls for the hook and breakout rooms for the lab; keep a producer for tech issues.
